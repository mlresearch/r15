abstract: We discuss the computational complexity of approximating maximum a posteriori
  infer- ence in sum-product networks. We first show NP-hardness in trees of height
  two by a reduc- tion from maximum independent set; this im- plies non-approximability
  within a sublinear factor. We show that this is a tight bound, as we can find an
  approximation within a linear factor in networks of height two. We then show that,
  in trees of height three, it is NP-hard to ap- proximate the problem within a factor
  2f(n) for any sublinear function f of the size of the input n. Again, this bound
  is tight, as we prove that the usual max-product algorithm finds (in any network)
  approximations within factor 2c\cdotn for some constant c < 1. Last, we present
  a sim- ple algorithm, and show that it provably pro- duces solutions at least as
  good as, and poten- tially much better than, the max-product algo- rithm. We empirically
  analyze the proposed algorithm against max-product using synthetic and real-world
  data.
